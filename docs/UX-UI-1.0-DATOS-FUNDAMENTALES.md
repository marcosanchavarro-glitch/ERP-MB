# Datos fundamentales — propuesta pendiente de definición

No se creó una ruta ni una pantalla vacía. La expresión puede referirse a datos
maestros de la comunidad o a configuración institucional: son alcances diferentes.

Opciones existentes que podrían enlazarse después de confirmar el propósito:

- Personas / Matriz y Células, para consultar los registros centrales.
- Calidad de datos e Importar / Exportar, para mantener la Matriz.
- Configuración de sede y organización territorial, para información institucional.

No se trasladaron módulos ni se duplicaron herramientas. Oficina se agrupó solo
para presentación en Trabajo diario, Comunidad y Datos y revisión, conservando
las rutas y los accesos recibidos del sistema.

Falta confirmar el propósito de «Datos fundamentales» y las herramientas incluidas.
Su implementación no implica otorgar nuevos accesos.
